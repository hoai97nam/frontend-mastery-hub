## 🛠 Tech Stack
- **Languages:** JavaScript (ESNext), TypeScript, C# (for backend/patterns study)
- **Algorithms & DS:** Sorting (QuickSort, MergeSort, TimSort), Filtering (Binary Search, Sliding Window, Trie, Fuzzy Search), Data Structures (Linear, Hash, Tree, Graph, Modern DS)
- **Frameworks:** React, Angular, Vue, .NET (for architecture patterns study)
- **Styling:** Tailwind CSS, SCSS
- **State Management:** Redux, Pinia, RxJS/Signals
- **Architectures:** Micro Frontends (Module Federation, Web Components), SOLID, GoF Design Patterns
